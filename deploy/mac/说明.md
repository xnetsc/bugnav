# 在 Mac 上用容器跑 bugnav（不污染系统）

全部东西只在这一个文件夹 `~/bugnav` 里：代码、配置、数据都在其中，
运行环境是 Docker 容器，Mac 系统里不装任何 Python 包。
不用时一条命令停掉，删掉文件夹即彻底清除。

## 第一次启动（约 2 分钟）

1. 打开「终端」（聚焦搜索输入 Terminal 回车）；
2. 粘贴这一行回车：

   ```
   bash ~/bugnav/start-bugnav.sh
   ```

3. 按提示输入两样东西（只问这一次）：
   - 科沃斯账号**短 ID**（App → 我的 → 账号资料，形如 `EXXXXXXX`，别填手机号）；
   - 科沃斯账号**密码**（输入时不显示，是正常的）。密码只写进本文件夹的
     `.env`（权限 600），不进任何云端、不发给任何人。
4. 脚本会自己拉起 Docker、构建并启动容器，最后打印日志。
   看到 `connected to device` 和 `runner started` 就是通了。

## 工作方式

程序实时看着机器人的位置和状态，该出手时真的指挥它：监督裁决
（停机/回站/询问/充电续扫）真实下发；卡困前兆（挣扎、猛冲、绕圈）
原地暂停、停稳后恢复同一个清扫会话继续扫，不重置它的清扫进度；
真楔死动不了时才用遥控步进后退脱困，退不出来就停机、响提示音
并发通知等人工救援。全是真实动作。

## 常用命令（都在终端里）

```
看日志:  docker compose -f ~/bugnav/docker-compose.yml logs -f bugnav
状态:    docker compose -f ~/bugnav/docker-compose.yml ps
停止:    docker compose -f ~/bugnav/docker-compose.yml down
再启动:  bash ~/bugnav/start-bugnav.sh
```

## 注意

- Mac 合盖/睡眠时容器会暂停，机器人就回到原厂行为——所以 Mac 只适合
  验证期；要 7×24 常开，后续再迁到小主机或云服务器（配置和数据拷过去即可）。
- 登录若失败：先确认短 ID 没填成手机号、密码里没有特殊字符问题；
  把日志最后几行发我看。不要反复改 device_id（会触发科沃斯的设备验证）。
